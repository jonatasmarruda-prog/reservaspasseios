# Nosso Controle

Aplicativo PWA de controle financeiro familiar compartilhado.

## Recursos
- Login individual por e-mail e senha
- Família compartilhada por código de convite
- Receitas, despesas, pendências e realizados
- Contas e salários recorrentes
- Fechamento mensal previsto x realizado
- Comprovantes privados no Supabase Storage
- OCR local no navegador para sugerir valor/data do comprovante
- Exportação CSV e impressão de relatório
- Instalação na tela inicial do celular

Os dados financeiros não ficam neste repositório. O front-end usa Supabase Auth, RLS e Storage privado.
